# CPython 3.13 .pyc to Path B IR (first subset)

Status, 2026-11-26: the `.pyc` reader (`tools/cpython/cpy_marshal.{hpp,cpp}`) reads CPython 3.13 timestamp-based `.pyc`
files (marshal version 5, with references and code objects). The lowering (`tools/cpython/cpy_lower.{hpp,cpp}`) turns the
module's code and the functions defined at module level into the IR of docs/notes/pathb-stage2.md, with `(producer
"cpython-3.13")`. `tests/cpython/lower/run.sh` runs each program through lowering, the emitter, QBE and a link, and checks it
against python3 (3.13.18). Nothing else is lowered: every other construct is refused with a named reason and exit status 3.

## Pipeline

```
.py -> python3 -m py_compile (3.13 .pyc)
    -> cpy_lower: header + marshal reader (cpy_marshal) -> IR text (cpy_lower)
    -> scripts/mrb.rb scripts/pathb-qbe-emit.rb -> QBE IL -> build/qbe/qbe -> assembly
    -> cc with tests/cpython/runtime (pyrt.c helpers, driver.c prints `result`)
```

`tools/cpython/cpy_opcodes.inc` is generated by `tools/cpython/gen_opcodes.py` from the running 3.13 interpreter (opcode
numbers, inline cache sizes, relative jumps). Regenerate it with `python3 tools/cpython/gen_opcodes.py` on 3.13.

## What is lowered

- Values: int constants up to 62 bits, True, False, None. Ints are 64-bit at run time; a result beyond 64 bits stops the
  program with `RuntimeError: integer result beyond 64 bits (bignums are not lowered yet)`.
- Module names are read and written with LOAD_NAME/STORE_NAME (CPython's module-level opcodes), and inside functions with
  LOAD_GLOBAL/STORE_GLOBAL (with `global`). A global is a 32-byte object that starts UNBOUND; reading it before it is bound
  raises `NameError`.
- Fast locals: LOAD_FAST, LOAD_FAST_CHECK, STORE_FAST and the 3.13 superinstructions (LOAD_FAST_LOAD_FAST,
  STORE_FAST_LOAD_FAST, STORE_FAST_STORE_FAST). A read of an unbound local raises `UnboundLocalError`.
- Operators: BINARY_OP for `+ - * // %` (and their in-place forms), COMPARE_OP for the six comparisons, unary `-` and
  `not`, TO_BOOL. Python's floor division and modulo; `ZeroDivisionError` with CPython's messages.
- Control flow: POP_JUMP_IF_TRUE/FALSE, POP_JUMP_IF_NONE/NOT_NONE, JUMP_FORWARD, JUMP_BACKWARD(_NO_INTERRUPT), `while`,
  `for` over `range()` (FOR_ITER, END_FOR), `break`, `continue`, `return` from inside a loop.
- Stack shuffles: COPY, SWAP, PUSH_NULL, POP_TOP, RESUME, NOP.
- Calls: a call of a `def` at module level with the same number of positional arguments, including recursion and calls
  to a function defined later in the module (NameError if the module has not run the def yet). `range(stop)`,
  `range(start, stop)` and `range(start, stop, step)` in a `for`.

## What is refused (exit 3, "refused: ...")

Each refusal names the construct; `lower/err/*.py` holds one program per category:

- generators and coroutines (CO_GENERATOR and friends; YIELD_VALUE, RETURN_GENERATOR);
- classes (LOAD_BUILD_CLASS), imports (IMPORT_NAME), f-strings (FORMAT_SIMPLE, BUILD_STRING), comprehensions
  (LOAD_FAST_AND_CLEAR, and their exception-table regions);
- `*args`, `**kwargs` and keyword arguments (CO_VARARGS, CO_VARKEYWORDS, CALL_KW, CALL_FUNCTION_EX, a tuple of keyword names);
- closures and nested defs (cells, free variables, MAKE_CELL, a def inside a function), and default arguments or annotations
  (SET_FUNCTION_ATTRIBUTE);
- exceptions: a try, with or assert (the exception table, RAISE_VARARGS, LOAD_ASSERTION_ERROR);
- constants other than the ones above: floats, strs, bytes, tuples, big ints (more than 62 bits), Ellipsis;
- containers (BUILD_LIST and friends), attributes (LOAD_ATTR), subscripts, `del`, `in` (CONTAINS_OP), `is` (IS_OP);
- binary operators other than `+ - * // %`: true division, `**`, bit operators, shifts, `@`;
- a name that is never assigned in the module (builtins such as `abs` or `len`, which are not lowered), and a def name
  that is bound twice;
- a function object used as a value (`x = f`), a call of a computed callable, a call with the wrong number of arguments,
  a method call, `range()` used other than by a `for`;
- hash-based `.pyc` files (flags != 0), and any magic number other than CPython 3.13's.

## Design

- Each code object is one IR function `pyf_K(PV *ret, PV *args)`; `pyf_0` is the module. A PV is 32 bytes: a tag and three
  payload words. The operand stack and the fast locals are frame slots (`stk`, `loc`), so an instruction's stack depth gives
  a fixed address. The lowering tracks a compile-time kind for each stack entry (value, NULL, function, `range` builtin,
  iterator, code), so a call resolves statically, and a function used as a value is refused rather than guessed.
- The IR holds the control flow, the frame and the calls. Arithmetic, comparisons, truth tests, `range` and the error
  messages are runtime helpers (`tests/cpython/runtime/pyrt.c`), which is how the producer keeps Python's exceptions out of the
  IR (docs/notes/pathb-stage2.md, section 1: runtime concerns stay with the producer).
- Labels are the byte offsets of the instructions. A FOR_ITER that is exhausted jumps to END_FOR with one dummy entry more,
  as `dis.stack_effect` gives. A merge of two stacks with different kinds is refused.

## Tests

`tests/cpython/lower/run.sh` (needs python3 3.13; `MRB` names an mruby interpreter for scripts/mrb.rb):

- `lower/*.py`: the printed `result` must equal python3's, and the exit status 0.
- `lower/rterr/*.py`: exit 1, and the exception line that python3 prints last must appear on stderr.
- `lower/err/*.py`: exit 3 with `refused:` on stderr and nothing on stdout.
- The header: a .pyc with another magic number and an unchecked-hash .pyc are refused.

## Not yet

Bignums, floats, strings, tuples, lists, dicts, attribute access, the rest of the operators, builtins other than `range`
(`print`, `len`, ...), generators, classes, closures, exceptions, `*args`/`**kwargs`, keyword arguments, default arguments,
imports, comprehensions and f-strings. Calls through values (a function stored in a list, a bound method) are refused.
Recursion depth is limited by the C stack, not by Python's recursion limit. Unbounded recursion overflows the C stack.
