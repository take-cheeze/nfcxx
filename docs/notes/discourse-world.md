## Runtime blockers in the fork

- Missing methods: `Integer#to_f`, `Module#private_constant`, `String#ascii_only?`. Porting is in progress on `claude/runtime-methods-discourse`.
- Integer overflow does not promote to bignum (`2**70` is a Float even with `MRB_USE_BIGINT`).
- Marshal: `mruby-marshal` links and round-trips all non-bignum values. The fork's copy is `claude/marshal-link` (`697c7b942`). nfcxx still uses the submodule.

## Order of work

1. Runtime methods on the fork (above), then pin them in nfcxx.
2. pg converter gaps: measure with the corpus flags, fix the largest converter-side category, and separate true design gaps (VALUE as pointer, libpq linking, parent data types).
3. Remaining native gems: nokogiri, ffi, google-protobuf, sqlite3 (only if production uses them).
4. Rails 8.1 signatures are generated by `tools/rbs-import` into `bc2cpp/sig/imported/` (git-ignored). bc2cpp does not load them yet.
5. A bc2cpp world for Discourse: entry point, the closed-world list of gems, and the native gems linked against the built fork. Not started.
