nfcxx wasm explorer

C++, C, Rust, Go, LLVM IR → mid-level IR → WebAssembly, run in this page checking server…

This is the static build: the examples are compiled ahead of time, and other code needs the local server (node tools/wasm-explorer/server.cjs, see docs/notes/wasm-explorer.md).

This page compiles C, C++, LLVM IR and the IR itself: EDG's front end and the wasm emitter run here, as wasm (about 5 MB to download, the first time something other than an unedited example is compiled). Rust and Go, and programs that include the C or C++ library headers, need the local server (node tools/wasm-explorer/server.cjs).
