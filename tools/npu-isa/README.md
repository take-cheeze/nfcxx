# NPU 5000 (SHAVE 5000xx) assembler/disassembler experiments

Working tools for decoding and encoding SHAVE instructions for the Intel NPU 5000, built by
learning encodings from the MoviTools assembler (`moviAsm64.dll`) as an oracle.

Status: partial. Coverage of the OpenVINO blobs tested so far is about 51%, and only 17 of
148 blobs decode fully. See `NOTES.md` for the findings and open blockers.

## Files

- `NOTES.md`: working notes, verified encodings, open questions.
- `asmbatch.c`: Windows host program (built with MinGW) that loads `moviAsm64.dll` and assembles
  many instructions in one process. Usage: `asmbatch.exe <MVC_DEPEND root> <in.txt> <out.txt> <target>`.
- `learn_list.py`: runs `asmbatch.exe` under wine (`~/.wine-movi`) and returns the encoded bytes.
- `decode_generic.py`, `decode_kernel.py`: the decoder (templates, bundle headers, special cases).
- `rt.py`: round trip (decode, reassemble, compare).
- `census4.py`: coverage census over a directory of `.blob` files (expects `/home/takecheeze/ov-eval`).
- `unit_classes.py`: discovers which mnemonics assemble, and their opcode classes, for one unit.
- `shavelib.py`: extracts the `shave.text` section from an ELF blob.
- `all_templates.json`, `classes*.json`, `tuple_hdr*.json`, `mnemonics.txt`: learned tables.
- `gen/`: small kernels generated by the compiler, with assembler text and binaries as fixtures.

## Not included

- `moviAsm64.dll`, `moviCompile64.dll`, `moviLLD64.dll` and the MoviTools installation. These are
  Intel's proprietary tools; obtain them separately and set `MVC_DEPEND` to their root.
- The OpenVINO `.blob` files used for the census.

## Requirements

- Python 3, plus wine with a prefix at `~/.wine-movi` that has MoviTools installed under `C:\movi`.
- Target string `5000xx`. `3720xx` produces incorrect code on this device.
